# uppjs.com

「让技术说人话，让每个人用上 AI」—— 一个不接推广、不做商业排序的工具站。
收录标准只有一条：**我真的在用、而且用得住**。

线上地址 → https://uppjs.com

---

## 这个仓库是什么

网站的**全部源文件**。根目录只放两类东西：

| 放什么 | 长什么样 |
|---|---|
| 要发布出去的页面 | `*.html`（全部由 build.py 自动生成，**不要手改**） |
| 双击就能用的入口 | `*.command`（改内容、更新网站、同步书签、体检链接……） |

**所有 markdown 内容源都在 [`内容源/`](内容源/) 文件夹里**，根目录一个 .md 都不留
（除了你现在看的这一份 —— 它是给 GitHub 仓库首页看的，不参与编译）。

## 怎么写内容

内容源是纯 markdown，只有四种写法：

```markdown
## 大分类                  → 页面上的一级分类，左侧目录里能看到
- 小分组：                  → 分类下的分组，点标题可以折叠
    - [名称](网址)：一句话说明     → 单个条目
        - 补充说明                  → 条目下面再挂一行小字
```

加一条就复制一行 `- [名字](网址)：说明`，改掉内容。
不想写网址也可以，直接写名字，一样能搜到。
（免费资源那页还支持 `- [☆ 名称](网址)：说明`，名称前加 ☆ 会在右边挂一个「荐」。）

## 怎么更新

全程双击，不用碰命令行：

1. 双击 **`1-编辑内容.command`** → 改对应的 `.md` → 保存
2. 双击 **`2-更新网站.command`** → 生成网页 + 提交 + 推送
3. 约 1 分钟后线上生效

手动等价命令：

```bash
python3 build.py && git add -A && git commit -m "更新" && git push
```

## 站点原则（硬规则）

- **不接推广、不做商业排序** —— 收录顺序不代表任何商业关系
- **不收集数据**：没有统计脚本、没有 Cookie、没有第三方请求
- **纯静态**：每个页面单文件、零依赖、断网可用
- **合法性**：不收盗版影视 / 破解软件 / 种子站 / 翻墙工具
