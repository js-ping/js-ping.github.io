# uppjs.com

「让技术说人话，让每个人用上 AI」—— 一个不接推广、不做商业排序的工具站。
收录标准只有一条：**我真的在用、而且用得住**。

线上地址 → https://uppjs.com

---

## 这个仓库是什么

网站的**全部源文件**。根目录只放两类东西：

| 放什么 | 长什么样 |
|---|---|
| 要发布出去的页面 | `*.html`（全部由 build.py 自动生成，**不要手改**） |
| 双击就能用的入口 | `*.command`（改内容、更新网站、同步书签、体检链接……） |

**所有 markdown 内容源都在 [`内容源/`](内容源/) 文件夹里**，根目录一个 .md 都不留
（除了你现在看的这一份 —— 它是给 GitHub 仓库首页看的，不参与编译）。

## 怎么写内容

内容源是纯 markdown，只有五种写法：

```markdown
## 大分类                  → 页面上的一级分类，左侧目录里能看到
- 小分组：                  → 分类下的分组，点标题可以折叠
    - [名称](网址)：一句话说明     → 单个条目
        - 补充说明                  → 条目下面再挂一行小字
    - 名称 [Mac]：一句话说明       → 方括号里标平台，名称右边出小徽章
```

加一条就复制一行 `- [名字](网址)：说明`，改掉内容。
不想写网址也可以，直接写名字，一样能搜到。
（名称前加 `☆` 会在右边挂一个「荐」。）

### 平台标记

只在**挑系统**的时候写，不写就是多平台通用（不显示徽章）：

```markdown
- [IINA](https://iina.io/) [Mac]：macOS 最强播放器……
- [Potplayer](https://wwzt.lanzoul.com/xxx) [Win]：音视频播放器。
- [wow 时钟](https://wowclock.moonfoxer.com/) [安卓]：桌面时钟小组件……
```

能写的：`[Mac]` `[Win]` `[iOS]` `[安卓]` `[网页]`，一条可以写多个（`[Win] [安卓]`）。
别名都认：`macOS` / `mac` / `Windows` / `PC` / `iPhone` / `Android`。
标了之后，页面上的搜索能搜到（输入 `mac`、`windows`、`安卓` 都行），
筛选下拉里也会多出「只有 Mac 版 / 只有 Windows 版」。

## 怎么更新

**日常改内容：双击 `8-内容编辑器.command`。**

浏览器里会打开一个本机网页（只监听 127.0.0.1，外网连不上），像填表格一样
加条目、改条目、拖动排序，底部实时显示这一条会写成什么 markdown。
点「预览」看效果（生成到 `本地资料/预览/`，不影响线上），点「保存并上线」发布。

**想直接改 markdown：双击 `1-编辑内容.command`。**

1. 双击 **`1-编辑内容.command`** → 改对应的 `.md` → 保存
2. 双击 **`2-更新网站.command`** → 生成网页 + 提交 + 推送
3. 约 1 分钟后线上生效

手动等价命令：

```bash
python3 build.py && git add -A && git commit -m "更新" && git push
python3 build.py --preview   # 只生成到 本地资料/预览/，连空页也出一份，用来先看效果
```

编辑器改过一次代码后，跑一下 `scripts/编辑内容/自检.command`（24 项回归测试，
主要验「改一个条目时别的地方一个字节都不能动」）。

## 还没上线的页面

书单 / 影单 / 文章归档在 `build.py` 的 `LIST_PAGES` 里是 `enabled="auto"`：
**填了第一条内容才会上线**，空着的时候首页显示成「规划中」。
网址书签页是 `enabled=False`，数据一直留着，想恢复改成 `True` 即可。

## 站点原则（硬规则）

- **不接推广、不做商业排序** —— 收录顺序不代表任何商业关系
- **不收集数据**：没有统计脚本、没有 Cookie、没有第三方请求
- **纯静态**：每个页面单文件、零依赖、断网可用
- **合法性**：不收盗版影视 / 破解软件 / 种子站 / 翻墙工具
