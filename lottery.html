一个纯网页彩票辅助工具（无需 Python，拷到任何电脑双击 index.html 就能用），包含四个模块：

模块干什么用入口

⚽ 大乐透选号同上，规则参数按大乐透标定首页 → 大乐透卡片

先说最重要的：所有排除规则不会提高任何一注的中奖概率（双色球恒定 1/17,721,088，大乐透恒定 1/21,425,712）。规则的真实作用只有两个：① 复式缩水少花钱；② 避开大众生日号，万一中了减少平分人数。2元娱乐，量力而行。

三、选号页详解

3.1 两种机选模式（同一个按钮自动分流）

你的操作效果
什么都不选，直接点 🎲 按规则机选全号池随机抽号，逐注过规则校验，等价于投注站机选（只是剔除了极端形态）
先点选候选（红球≥6个、蓝球≥1个；大乐透前区≥5、后区≥2），再点 🎲 按规则机选先列出你候选范围内的全部组合，用规则过滤缩水，再从通过的组合里随机抽「注数」那么多注。结果栏会显示：候选空间 X 注 → 过滤后剩 Y 注 → 机选 N 注

结果栏里每注都标注和值，方便核对。

3.2 「🎲 帮我随机选候选」按钮

不想动脑圈范围时，点它会随机帮你点亮一组候选号（前区10个、后区3个左右），然后再机选，就是在"这个随机范围"内选号。想强制带 32/33 避开生日党时，先手动点亮 32/33 再点它补齐。

  3. 点 核对，工具会对照该彩种成立以来全部历史开奖逐期判奖

结果说明：显示每注的最佳战绩——奖级、命中个数、对应期号和日期。双色球按 6+1 判一至六等奖，大乐透按 5+2 判一至九等奖，均按官方规则。一/二等奖为浮动奖金，工具只标注奖级不估金额。

💡 核对器对照的是历史全部开奖而非仅最新一期——所以也能玩"如果这注号在过去23年里买过会怎样"。

6.1 这些开奖数据到底从哪来

官方的两个接口对境外 IP 是直接拒绝的（实测：福彩官网对境外出口返回 403，体彩接口返回 567，连站点首页都打不开），改 UA、加 Referer 都没用 —— 这不是反爬，是地域封锁。所以本站服务器按下面的顺序逐个试，谁能用用谁，并把实际用的那一个原样写在页脚上：

顺序数据源什么时候会命中
1中国福利彩票官网 / 中国体彩网官方接口。服务器出口在大陆时优先命中，拿到的就是第一手数据
217500.cn第三方数据站。内容是官方开奖公告的转录 —— 服务器在境外时实际最常用它
317500.cn 备用域名 / http 入口同一份数据的备用入口，只在前两个都不通时才用
—页面内嵌快照上面全都拿不到时。此时页脚写「数据内嵌」，页面照常可用
需要知情：　17500.cn 是第三方站点，不是官方。本站取回它的数据后会逐行校验（期号必须严格递增、日期格式、球的个数、取值范围、最新一期不能太旧），任何一行不合规就当这个源失效、换下一个；整份校验通过才合并进历史。实测官方接口与 17500.cn 在 100 个重叠期上逐期完全一致。
但你要知道这条路的前提：它依赖一个第三方站点的可用性。那个站改版或失效时，自动更新会暂时退回内嵌快照 —— 只会「更新不到」，不会给出错误数据。

6.2 为什么不干脆只用自己的服务器去抓官方

因为「服务器在哪」决定了能不能抓到官方接口：

做法能不能拿到官方接口代价
本站现在这样（境外边缘节点）不能，被 403 / 567零成本，但要靠 17500.cn 中转
自建大陆云函数（函数 URL）能需要注册实名账号，免费额度够用；接口地址固定不变
自己的域名 + 大陆服务器 + ICP 备案能要备案、要买服务器，是最重的一条路

所以本接口的源表把官方放在第一位：将来若接上大陆出口，代码一行都不用改，第 1 级自动就命中了。

无论如何，最终以官方开奖公告为准。本工具只做娱乐辅助，不构成任何购票依据。

七、常见问题

Q：点机选没反应或报错？

工具本身在你浏览器里跑，不依赖任何服务器，不存在"服务停了"的问题。如果页面空白，按 Cmd+Option+R 强制刷新即可。

Q：过滤后剩 0 注？

候选范围太小而规则全开时会这样。取消几条规则（如三区间、同尾），或扩大候选。

Q：页面显示不对劲？

按 Cmd+R 强制刷新。工具已禁用缓存，正常情况不会出现旧页面。

Q：我的票会被上传吗？

不会。历史开奖内嵌在页面里；你录入的票据只存在你自己的浏览器里，不上传任何地方。页面唯一的外部请求是本站自己的开奖接口，不向任何第三方发送数据。

Q：换电脑能用吗？

能，这正是单文件网页版的特长：把 lottery.html 拷到 U 盘、或用微信传过去，Windows / Mac / Linux 双击就能用，什么都不用装，断网也能用。
