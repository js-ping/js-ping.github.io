使用说明

线上地址：https://uppjs.com

这份说明写给完全不想碰命令行的人。从头到尾，你只需要会两件事：改文件、双击一个图标。

（书签页稍微不同——它不用改文件，你在 Chrome 里收藏，本地网页就自动跟着变。见第二节的动作 3。）

一、30 秒了解这个网站

这是一个纯静态的个人清单站，一共五个页面：

页面网址内容是什么内容从哪来
首页uppjs.com导航：软件清单入口 + 各页面入口不用改，自动生成
软件清单uppjs.com/apps.html软件、硬件、外设你手写 README.md
网址书签uppjs.com/links.html常用网站和在线工具自动同步你的 Chrome 书签
彩票选号uppjs.com/lottery.html双色球 / 大乐透选号、购票核对、走势图独立小工具，装上就不用管
使用说明uppjs.com/help.html就是本文使用说明.md

四个清单页长一个样：顶上是搜索框，左边是目录，右上角能换配色。搜索是全站通用的——打几个字，几个页面里的内容都能立刻查出来。（彩票选号是独立的小工具，有自己的界面。）

一句话原理：你写 markdown 文件 → 双击一个图标 → 脚本把 markdown 编译成网页 → 自动传到网上。
网页文件（.html）永远不要手改，每次都会被覆盖。

>

唯一的例外是书签页：它不用你手写，脚本直接读 Chrome 的书签，你在 Chrome 里收藏就等于在改它。

二、日常只有三个动作

动作 1：改内容

双击 1-编辑内容.command → 自动用 VSCode 打开 README.md。

步骤做什么
1双击 1-编辑内容.command
2在编辑器里改内容：加一条、改说明、调分类
3想看效果：光标放正文里，按 Cmd + K 松开，再按 V，右侧弹出实时预览
4按 Cmd + S 保存。不保存等于没改
5关掉 VSCode，去双击 2-更新网站.command

想改「网址书签」页？不要手改 links.md——它是 同步书签.py 生成的，下次同步就被覆盖。要调分类规则，改 同步书签.py 里的 RULES（什么网址归到哪一类）和 CATS（分类的名字和顺序），见第七节 FAQ。

为什么是 VSCode： 改 Markdown 最顺手——有语法高亮、有实时预览、Cmd + F 找东西、Cmd + Z 一路撤销。项目里还配好了设置：长行自动换行、中文标点不会被误报成"可疑字符"，打开就能用。

说到底，内容源就是个纯文本文件，用哪个编辑器都行。
只有一条禁忌：别用 Word / Pages 这类富文本编辑器打开，它们会往里塞格式代码，把文件搞坏。

动作 2：更新上线

双击 2-更新网站.command，剩下的全自动：

步骤自动做什么
①编译四个页面，并告诉你共多少个分类、多少条
②把改动提交到 git
③推送到 GitHub
④打开本地预览，弹窗告诉你结果

看到「✓ 完成」就成了，大约 1 分钟后线上更新。

网络不通怎么办？ 推送可能失败，但改动已经安全存在本地，一个字都不会丢。等网络好了重新双击 2-更新网站.command 即可。

动作 3：让书签自己同步（只做一次）

「网址书签」页不用你手写。双击一次 3-同步书签.command，它会挂在那儿盯着 Chrome 的书签文件：

你做什么它会做什么
在 Chrome 里收藏一个网站十几秒后，本地网页自动更新（但不会自动上线）
在 Chrome 里删掉一个书签网页上对应的条目也跟着消失
把书签从「常用」拖到「软件」网页上按网址重新归类（网站在哪个 Chrome 文件夹里，不影响网页分类）
关掉那个终端窗口停止监听，不留任何后台进程

这就是全部操作。 双击一次，然后该干嘛干嘛，平时完全不用管它。

为什么切换 Chrome 文件夹不影响网页分类？
因为分类是按网址判的，不是按你放哪儿。你把一个 GitHub 链接拖到任何文件夹，它在网页上永远在「开发与编程 › GitHub 精选」。这样你整理 Chrome 时不用小心翼翼。

想上线时：双击 2-更新网站.command，它会把攒下的书签改动一次性提交并发布。从双击到线上生效约 1 分钟（本地编译几秒 + 云端构建部署实测约 30 秒）。

为什么默认不自动上线？
整理书签时你往往连着改几十下。每改一次就推一次 = 几十个 git 提交 + 几十次云端重新部署，全是噪音。
攒着一次性推，提交历史干净，云端也只构建一次。

>

想恢复成「改一次上一次」：打开 3-同步书签.command，把开头的 AUTO_PUSH=0 改成 1。

不想公开某个书签怎么办？ 见下一节。

三、内容怎么写（这一节最要紧）

打开 README.md，满屏 markdown。别怕，真正会用到的写法只有四种：

写法长什么样页面上是什么
大分类## Mac 软件一级分类，出现在左侧目录里
小分组- 装机必备：（冒号结尾）可折叠的分组标题
一条条目- [名称](网址)：一句话说明一个条目，能点开链接
补充一行再缩进一级的 - 小字说明挂在条目下面的小字

就这四种，没有别的规则。

一条条目怎么拆

- [IINA](https://iina.io/)：Mac 上最好用的免费播放器｜就是启动稍慢
  └─ 名称 ─┘ └── 网址 ──┘ └──── 说明 ────┘ └─ 个人点评 ─┘
部分必须吗说明
名称必须中括号里的字，页面上显示的名字
网址不必须圆括号里。不写也行，只显示名字，一样能搜到
说明不必须冒号后面第一段，跟名字同一行显示
个人点评不必须用全角竖线 ｜ 隔开的第二段，单独一行、灰色小字
补充小字不必须再缩进一级写，挂在条目下面

页面上所有数字（目录里的条数、页脚的总数）都是脚本自己数出来的，你不用管。

💡 点评是这个清单最值钱的部分。 网上软件介绍到处都是，但"文件一多就卡""盗版太多，还在找笔中"这种话只有你能写。这是区别于软件测评号的地方，值得每条都补一句。

想干什么，就怎么写

想干什么怎么写
加一条软件复制一整行 - [名字](网址)：说明，改掉内容
加一个分组写 - 分组名：，下面缩进写条目
只记个名字，没有网址- 小米巨能写。 直接写，不加括号
一条挂好几行小字再缩进一级继续写 - 小字
标一个"推荐"名称前加 ☆，页面上会出现一个「荐」徽章
标记一个已弃用用 ~~删除线~~ 包起来，页面上变灰并加删除线
想写给自己看的备注用 <!-- 备注 -->，网页上完全不出现

换个说法也能认，但建议统一

脚本对下面这些写法全都认，但混着用页面会看起来不齐整，建议统一成一种：

你可能会写推荐写成
- 名字，一句话说明- 名字：一句话说明
- [名字](网址),说明- [名字](网址)：说明
- 名字 。 说明- 名字：说明
名称里塞 （6.25 版本） （专业版）照写没问题，会原样留在名称里

记住一句话：名称和说明之间，用中文冒号 ： 隔开。

下面这种写法已经不用了

以前给每条软件底下挂过几行「规格」：

- [Ollama](https://ollama.com/)：命令行拉起本地模型。
    - 免费：是
    - 开源：是
    - 平台：Win / macOS / Linux

现在页面上不显示这几行了，写了也不会出现。想说的信息直接写进那一句话里：

- [Ollama](https://ollama.com/)：命令行拉起本地模型，模型文件很占硬盘，动手前先看剩余空间。

顺带一提，说明末尾要不要加句号都行——加了脚本会自动去掉，页面上更齐整。

四个最容易踩的坑

坑会怎样怎么避免
用 Tab 键缩进层级会乱只用空格，一层 2 个或 4 个都行，但要一致
只写 - 分组名：，下面没有缩进内容页面上就是一行孤零零的字分组下面至少放一条缩进的条目
一个井号 # 标题只认两个井号 ##，一个井号会被当普通文字分类一律用 ##
一条里塞两个链接第二个会跑进说明里拆成两条最清楚

加一条软件的完整例子

## Mac 软件

- 装机必备：
    - [IINA](https://iina.io/)：Mac 上最顺手的视频播放器，几乎什么格式都能放。
        - 免安装解码器，双击就能用。
    - ☆ [Rectangle](https://rectangleapp.com/)：窗口管理，快捷键顺手，用久了离不开。
- 工具类：
    - [Mounty](https://mounty.app/)：让 Mac 能写入 NTFS 格式的 U 盘。

保存后双击 2-更新网站.command，一分钟后就出现在网上。

「网址书签」页怎么回事

这个页面不用你手写。它的内容来自你的 Chrome 书签，由脚本自动转换。

怎么改？在 Chrome 里改。 想加一个网站，就在 Chrome 里收藏它；想删，就在 Chrome 里删掉。你在 Chrome 里做的任何增删，十几秒后都会同步到网页上。

links.md 是脚本自动生成的中间产物。手改它会在下次同步时被覆盖——想加网址请去 Chrome 收藏，别改这个文件。

书签名会被自动洗一遍。 浏览器收藏时抓下来的标题常是一长串 SEO 垃圾，脚本会清掉站点名后缀、宣传语、表情符号、版本号，补上合适的名字：

Chrome 里的原标题网页上显示
`AI工具集官网 \1000+ AI工具集合，国内外AI工具集导航大全`AI工具集
GitHub - yt-dlp/yt-dlp: A feature-rich command-line…yt-dlp/yt-dlp
folivora.ai - Great Tools for your Mac!Alfred

链接里的 ?utm_source=chatgpt.com 这类跟踪参数会一并去掉，指向同一个网址的条目自动合并成一条。

书签页会显示网址域名（条目右边那个灰色小字）。同一个站点出现 5 次以上的（GitHub、CSDN、知乎这类）会自动隐藏，免得一屏全是同一个域名；搜索时按域名也能搜，输入 github.com 就能筛出所有 GitHub 条目。

哪些书签不会上网

三类内容不会出现在网页上：

类别怎么界定
你手动排除的放在 Chrome 里名为 不上网站 的文件夹里的（含它下面的子文件夹），一个都不发布
安全兜底自动挡的个人后台（抖音/微博/公众号后台、支付、云控制台）、政务网站（*.gov.cn）、破解激活站、成人内容、VPN 与机场、购物与网盘分享链接、彩票相关
重复的同一个网址收藏了多次，只留一条

想排除一个书签，最省事的做法：在 Chrome 书签栏新建一个文件夹，名字就叫「不上网站」，把不想公开的拖进去。以后想放回来，拖出来就行。

被自动兜底挡下的那批，可以一键收拢进来。 双击 4-整理不上网站.command，它会把命中的书签按原因分好类，搬进「不上网站」文件夹：

不上网站/
├── 个人后台            28 条
├── 政务与单位内部系统     25 条
├── 破解与激活码站        13 条
├── 成人内容             1 条
├── 机场与代理           19 条
├── 彩票相关             4 条
└── 购物与网盘分享        5 条

这样你在 Chrome 里一眼就能看清「到底哪些没上网、因为什么没上网」。想放行其中某一条，直接从文件夹里拖出来，十几秒后它就出现在网页上了（前提是它不再命中自动规则；命中了就得改规则，见下一小节）。

⚠️ 这一步会先退出 Chrome——Chrome 只在启动时读一次书签文件，边开边改会被它覆盖。脚本退出前会跟你确认一次，改完自动帮你重开，标签页会恢复。改之前还会把书签文件备份到 Chrome/_uppjs备份/。

>

网页内容不会因为这一步变化——这些书签本来就没被发布。

每次同步，终端里都会把「剔除了什么、每条因为什么被剔」印出来，不会偷偷丢东西。

想放行被自动挡掉的内容

打开 同步书签.py，往上找到 AUTO_BLOCK_RULES，里面按类别列着关键词：

("彩票相关", [r'lottery', r'彩票', r'体彩', r'福彩', r'中彩', ...]),
  • 想放行某一类 → 把那一组整段删掉
  • 想放行某一条 → 删掉对应的那个词
  • 想全部放行 → 把配置区的 AUTO_BLOCK = True 改成 False
建议等 Chrome 里的书签都归置妥当了再关兜底。现在留着更保险。

五、页面上的按钮都是干什么的

右上角「外观」

点开是一个小面板，四个选项：

选项作用
明暗自动 / 浅色 / 深色。选「自动」就跟系统走
底色8 种预设底色，点一下就换
自定义…弹系统取色器，自己挑任意颜色
恢复默认一键回到出厂配色

选完底色后，文字颜色会自动适配（浅底自动用深字，深底自动用浅字），不用担心看不清。实测标题对比度 ≥12:1、正文 ≥4.9:1，都在无障碍标准线以上。

设置只存在你自己这台浏览器里。换设备、换浏览器都是默认配色，也不影响别人，更不上传任何东西。

想加一种底色或改预设色： 打开 build.py 搜 presets，会看到一个数组，一行一个颜色：

{name: '暖阳', bg: '#f7efd9'},

name 是鼠标悬停时显示的名字，bg 是底色。加一行多一个色块，删一行少一个（面板一行排 4 个，建议保持 4 的倍数最整齐）。

搜索的几个小细节

  • 搜索时所有分组自动展开，命中的留下，没命中的自动收起。
  • 分组标题右边的数字变成 「命中数 / 总数」，一眼看出这一类里命中几条。
  • 大小写无所谓，中文英文都能搜。
  • 试试搜这几个词感受一下：截图、下载、pdf、heic。

十、数据安全与免责

关于隐私，这个网站的做法：

  • 纯静态页面：没有后端、没有数据库、没有统计脚本、不请求任何第三方 CDN。
  • 不收集任何访问数据，不埋点，不上报。
  • 本地存储只有一项：你的外观偏好，存在你自己的浏览器里，不会上传。
  • 页面上的链接指向第三方站点，点过去之后的行为不受本站控制。

书签同步的隐私边界（这段请务必看一遍）：

  • 同步全程只在你自己的电脑上跑。脚本读的是你本机的 Chrome 书签文件，写成本地网页，再推到你自己的 GitHub 仓库。中间没有任何第三方服务，书签不会被上传到任何别的地方。
  • 但要说清楚一件事：这个仓库是公开的。README.md、links.md 和生成的网页，任何拿到网址的人都看得到，GitHub 上也搜得到。
  • 所以：不想公开的东西，进 Chrome 之前就该放进「不上网站」文件夹。 自动兜底能挡住大部分明显不该公开的（个人后台、政务网站、破解站、成人内容、代理工具），但它是一条兜底防线，不是保证。
  • 脚本每次同步都会在终端里把剔除清单打出来。偶尔扫一眼，比事后补救便宜得多。

彩票选号工具的说明：

加一个新页面的完整步骤（想试的时候再看）：

  1. 新建一个内容源，比如 books.md，写法跟 README.md 一样。
  2. 打开 build.py，在 LIST_PAGES 里加一条：
dict(src="books.md", out="books.html", kicker="看过的书",
     title="书单", sub="带一句短评。", layout="list"),
  1. 双击 2-更新网站.command。页面、搜索、目录、配色、导航全都自动有，不用再写一行代码。
  2. 想让它出现在首页，再去 OTHER_PAGES 里加一行。

layout 有两个值："list" 是普通清单（软件页那种），"compact" 是紧凑排布（书签页那种）。
