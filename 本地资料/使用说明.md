# 使用说明

线上地址：<https://uppjs.com>

这份说明写给**完全不想碰命令行**的人。从头到尾，你只需要会两件事：**改文件**、**双击一个图标**。

> **这份说明只在你自己的电脑上，不会上线。**
> 它放在项目里的 `本地资料/` 文件夹，那个文件夹既不会提交到 GitHub，也不会出现在网站上。
> 想重新把它发布出去（比如以后想给朋友看），做法见第四节的「说明书为什么只在本地」。

## 一、30 秒了解这个网站

这是一个纯静态的个人清单站。**现在线上有三个页面**：

| 页面 | 网址 | 内容是什么 | 内容从哪来 |
|---|---|---|---|
| **首页** | uppjs.com | 导航：软件清单入口 + 工具入口 | 不用改，自动生成 |
| **软件清单** | uppjs.com/apps.html | 软件、硬件、外设 | 你手写 `README.md` |
| **彩票选号** | uppjs.com/lottery.html | 双色球 / 大乐透选号、购票核对、走势图 | 独立小工具，装上就不用管 |

**两个页面暂时下线了**——代码、内容源、脚本全都留着，随时一句话就能恢复：

| 页面 | 现状 | 怎么恢复 |
|---|---|---|
| **网址书签** | 先撤下来，等你把自己的 Chrome 书签整理完再说 | 把 `build.py` 里 `LIST_PAGES` 中 links 那条的 `enabled=False` 改成 `True` |
| **使用说明** | 改成只在本机看了，就是本文 | 把 help 那条加回 `OTHER_PAGES`，输出路径挪回根目录 |

清单页长一个样：顶上是搜索框，左边是目录，右上角能换配色。（彩票选号是独立的小工具，有自己的界面。）

> **一句话原理**：你写 markdown 文件 → 双击一个图标 → 脚本把 markdown 编译成网页 → 自动传到网上。
> 网页文件（`.html`）永远不要手改，每次都会被覆盖。

## 二、日常只有三个动作

### 动作 1：改内容

双击 **`1-编辑内容.command`** → 自动用 VSCode 打开 `README.md`。

| 步骤 | 做什么 |
|---|---|
| 1 | 双击 `1-编辑内容.command` |
| 2 | 在编辑器里改内容：加一条、改说明、调分类 |
| 3 | 想看效果：光标放正文里，按 `Cmd + K` 松开，再按 `V`，右侧弹出实时预览 |
| 4 | 按 `Cmd + S` 保存。**不保存等于没改** |
| 5 | 关掉 VSCode，去双击 `2-更新网站.command` |

想改「网址书签」页？**那个页面现在是下线的**，暂时不用管。等以后恢复了也**不要手改 `links.md`**——它是 `同步书签.py` 生成的，下次同步就被覆盖。要调分类规则，改 `同步书签.py` 里的 `RULES`（什么网址归到哪一类）和 `CATS`（分类的名字和顺序），见第七节 FAQ。

**为什么是 VSCode：** 改 Markdown 最顺手——有语法高亮、有实时预览、`Cmd + F` 找东西、`Cmd + Z` 一路撤销。项目里还配好了设置：长行自动换行、中文标点不会被误报成"可疑字符"，打开就能用。

> 说到底，内容源就是个**纯文本文件**，用哪个编辑器都行。
> 只有一条禁忌：**别用 Word / Pages 这类富文本编辑器**打开，它们会往里塞格式代码，把文件搞坏。

### 动作 2：更新上线

双击 **`2-更新网站.command`**，剩下的全自动：

| 步骤 | 自动做什么 |
|---|---|
| ① | 编译三个线上页面（首页 / 软件清单 / 彩票选号），并告诉你共多少个分类、多少条。说明书顺手在本地重生成一份 |
| ② | 把改动提交到 git |
| ③ | 推送到 GitHub |
| ④ | 打开本地预览，弹窗告诉你结果 |

看到「✓ 完成」就成了，**大约 1 分钟后**线上更新。

> **网络不通怎么办？** 推送可能失败，但改动已经安全存在本地，**一个字都不会丢**。等网络好了重新双击 `2-更新网站.command` 即可。

### 动作 3：让书签自己同步（现在可以跳过）

> ⚠️ **「网址书签」页目前是下线的，所以这一步现在做了也不会出现在网站上。**
> 下面写的这套东西全都还能用，等你想把书签页恢复上线时再看也不迟。
> 期间你在 Chrome 里正常收藏就行，双击 `3-同步书签.command` 会照常把它整理进 `links.md`，一条不丢。

「网址书签」页不用你手写。双击一次 **`3-同步书签.command`**，它会挂在那儿盯着 Chrome 的书签文件：

| 你做什么 | 它会做什么 |
|---|---|
| 在 Chrome 里收藏一个网站 | 十几秒后，本地网页自动更新（**但不会自动上线**） |
| 在 Chrome 里删掉一个书签 | 网页上对应的条目也跟着消失 |
| 把书签从「常用」拖到「软件」 | 网页上按网址重新归类（网站在哪个 Chrome 文件夹里，不影响网页分类） |
| 关掉那个终端窗口 | 停止监听，不留任何后台进程 |

**这就是全部操作。** 双击一次，然后该干嘛干嘛，平时完全不用管它。

> 为什么切换 Chrome 文件夹不影响网页分类？
> 因为分类是按**网址**判的，不是按你放哪儿。你把一个 GitHub 链接拖到任何文件夹，它在网页上永远在「开发与编程 › GitHub 精选」。这样你整理 Chrome 时不用小心翼翼。

**想上线时**：双击 `2-更新网站.command`，它会把攒下的书签改动一次性提交并发布。从双击到线上生效约 1 分钟（本地编译几秒 + 云端构建部署实测约 30 秒）。

> **为什么默认不自动上线？**
> 整理书签时你往往连着改几十下。每改一次就推一次 = 几十个 git 提交 + 几十次云端重新部署，全是噪音。
> 攒着一次性推，提交历史干净，云端也只构建一次。
>
> 想恢复成「改一次上一次」：打开 `3-同步书签.command`，把开头的 `AUTO_PUSH=0` 改成 `1`。

**不想公开某个书签怎么办？** 见下一节。

## 三、内容怎么写（这一节最要紧）

打开 `README.md`，满屏 markdown。别怕，**真正会用到的写法只有四种**：

| 写法 | 长什么样 | 页面上是什么 |
|---|---|---|
| 大分类 | `## Mac 软件` | 一级分类，出现在左侧目录里 |
| 小分组 | `- 装机必备：`（冒号结尾） | 可折叠的分组标题 |
| 一条条目 | `- [名称](网址)：一句话说明` | 一个条目，能点开链接 |
| 补充一行 | 再缩进一级的 `- 小字说明` | 挂在条目下面的小字 |

就这四种，**没有别的规则**。

### 一条条目怎么拆

```
- [IINA](https://iina.io/)：Mac 上最好用的免费播放器｜就是启动稍慢
  └─ 名称 ─┘ └── 网址 ──┘ └──── 说明 ────┘ └─ 个人点评 ─┘
```

| 部分 | 必须吗 | 说明 |
|---|---|---|
| 名称 | **必须** | 中括号里的字，页面上显示的名字 |
| 网址 | 不必须 | 圆括号里。**不写也行**，只显示名字，一样能搜到 |
| 说明 | 不必须 | 冒号后面第一段，跟名字同一行显示 |
| 个人点评 | 不必须 | 用全角竖线 `｜` 隔开的第二段，单独一行、灰色小字 |
| 补充小字 | 不必须 | 再缩进一级写，挂在条目下面 |

页面上所有数字（目录里的条数、页脚的总数）都是脚本自己数出来的，你不用管。

> 💡 **点评是这个清单最值钱的部分。** 网上软件介绍到处都是，但"文件一多就卡""盗版太多，还在找笔中"这种话只有你能写。这是区别于软件测评号的地方，值得每条都补一句。

### 想干什么，就怎么写

| 想干什么 | 怎么写 |
|---|---|
| 加一条软件 | 复制一整行 `- [名字](网址)：说明`，改掉内容 |
| 加一个分组 | 写 `- 分组名：`，下面缩进写条目 |
| 只记个名字，没有网址 | `- 小米巨能写。` 直接写，不加括号 |
| 一条挂好几行小字 | 再缩进一级继续写 `- 小字` |
| 标一个"推荐" | 名称前加 `☆`，页面上会出现一个「荐」徽章 |
| 标记一个已弃用 | 用 `~~删除线~~` 包起来，页面上变灰并加删除线 |
| 想写给自己看的备注 | 用 `<!-- 备注 -->`，网页上完全不出现 |

### 换个说法也能认，但建议统一

脚本对下面这些写法**全都认**，但混着用页面会看起来不齐整，建议统一成一种：

| 你可能会写 | 推荐写成 |
|---|---|
| `- 名字，一句话说明` | `- 名字：一句话说明` |
| `- [名字](网址),说明` | `- [名字](网址)：说明` |
| `- 名字 。 说明` | `- 名字：说明` |
| 名称里塞 `（6.25 版本）` `（专业版）` | 照写没问题，会原样留在名称里 |

**记住一句话：名称和说明之间，用中文冒号 `：` 隔开。**

### 下面这种写法已经不用了

以前给每条软件底下挂过几行「规格」：

```markdown
- [Ollama](https://ollama.com/)：命令行拉起本地模型。
    - 免费：是
    - 开源：是
    - 平台：Win / macOS / Linux
```

**现在页面上不显示这几行了**，写了也不会出现。想说的信息直接写进那一句话里：

```markdown
- [Ollama](https://ollama.com/)：命令行拉起本地模型，模型文件很占硬盘，动手前先看剩余空间。
```

顺带一提，说明末尾要不要加句号都行——加了脚本会自动去掉，页面上更齐整。

### 四个最容易踩的坑

| 坑 | 会怎样 | 怎么避免 |
|---|---|---|
| 用 Tab 键缩进 | 层级会乱 | **只用空格**，一层 2 个或 4 个都行，但要一致 |
| 只写 `- 分组名：`，下面没有缩进内容 | 页面上就是一行孤零零的字 | 分组下面至少放一条缩进的条目 |
| 一个井号 `# 标题` | 只认**两个井号** `##`，一个井号会被当普通文字 | 分类一律用 `## ` |
| 一条里塞两个链接 | 第二个会跑进说明里 | 拆成两条最清楚 |

### 加一条软件的完整例子

```markdown
## Mac 软件

- 装机必备：
    - [IINA](https://iina.io/)：Mac 上最顺手的视频播放器，几乎什么格式都能放。
        - 免安装解码器，双击就能用。
    - ☆ [Rectangle](https://rectangleapp.com/)：窗口管理，快捷键顺手，用久了离不开。
- 工具类：
    - [Mounty](https://mounty.app/)：让 Mac 能写入 NTFS 格式的 U 盘。
```

保存后双击 `2-更新网站.command`，一分钟后就出现在网上。

### 「网址书签」页怎么回事

> ⚠️ **这个页面目前是下线的**（2026-10-04 起），所以下面这些现在都不会体现在网站上。
> 之所以还留着这一节：内容源、脚本、分类规则全都在，等你整理完 Chrome 书签、想恢复的时候，照着这节做就行。

这个页面**不用你手写**。它的内容来自你的 Chrome 书签，由脚本自动转换。

**怎么改？在 Chrome 里改。** 想加一个网站，就在 Chrome 里收藏它；想删，就在 Chrome 里删掉。你在 Chrome 里做的任何增删，十几秒后都会同步到网页上。

> `links.md` 是脚本自动生成的**中间产物**。手改它会在下次同步时被覆盖——想加网址请去 Chrome 收藏，别改这个文件。

**书签名会被自动洗一遍。** 浏览器收藏时抓下来的标题常是一长串 SEO 垃圾，脚本会清掉站点名后缀、宣传语、表情符号、版本号，补上合适的名字：

| Chrome 里的原标题 | 网页上显示 |
|---|---|
| `AI工具集官网 \| 1000+ AI工具集合，国内外AI工具集导航大全` | `AI工具集` |
| `GitHub - yt-dlp/yt-dlp: A feature-rich command-line…` | `yt-dlp/yt-dlp` |
| `folivora.ai - Great Tools for your Mac!` | `Alfred` |

链接里的 `?utm_source=chatgpt.com` 这类跟踪参数会一并去掉，指向同一个网址的条目自动合并成一条。

**书签页会显示网址域名**（条目右边那个灰色小字）。同一个站点出现 5 次以上的（GitHub、CSDN、知乎这类）会自动隐藏，免得一屏全是同一个域名；搜索时按域名也能搜，输入 `github.com` 就能筛出所有 GitHub 条目。

#### 哪些书签不会上网

三类内容不会出现在网页上：

| 类别 | 怎么界定 |
|---|---|
| **你手动排除的** | 放在 Chrome 里名为 **`不上网站`** 的文件夹里的（含它下面的子文件夹），一个都不发布 |
| **安全兜底自动挡的** | 个人后台（抖音/微博/公众号后台、支付、云控制台）、政务网站（`*.gov.cn`）、破解激活站、成人内容、VPN 与机场、购物与网盘分享链接、彩票相关 |
| **重复的** | 同一个网址收藏了多次，只留一条 |

**想排除一个书签，最省事的做法**：在 Chrome 书签栏新建一个文件夹，名字就叫「不上网站」，把不想公开的拖进去。以后想放回来，拖出来就行。

**被自动兜底挡下的那批，可以一键收拢进来。** 双击 `4-整理不上网站.command`，它会把命中的书签**按原因分好类**，搬进「不上网站」文件夹：

```
不上网站/
├── 个人后台            28 条
├── 政务与单位内部系统     25 条
├── 破解与激活码站        13 条
├── 成人内容             1 条
├── 机场与代理           19 条
├── 彩票相关             4 条
└── 购物与网盘分享        5 条
```

这样你在 Chrome 里一眼就能看清「到底哪些没上网、因为什么没上网」。想放行其中某一条，**直接从文件夹里拖出来**，十几秒后它就出现在网页上了（前提是它不再命中自动规则；命中了就得改规则，见下一小节）。

> ⚠️ 这一步会先退出 Chrome——Chrome 只在启动时读一次书签文件，边开边改会被它覆盖。脚本退出前会跟你确认一次，改完自动帮你重开，标签页会恢复。改之前还会把书签文件备份到 `Chrome/_uppjs备份/`。
>
> 网页内容不会因为这一步变化——这些书签本来就没被发布。

每次同步，终端里都会把「剔除了什么、每条因为什么被剔」印出来，**不会偷偷丢东西**。

#### 想放行被自动挡掉的内容

打开 `同步书签.py`，往上找到 `AUTO_BLOCK_RULES`，里面按类别列着关键词：

```python
("彩票相关", [r'lottery', r'彩票', r'体彩', r'福彩', r'中彩', ...]),
```

- 想放行某一类 → 把那一组整段删掉
- 想放行某一条 → 删掉对应的那个词
- 想全部放行 → 把配置区的 `AUTO_BLOCK = True` 改成 `False`

> 建议等 Chrome 里的书签都归置妥当了再关兜底。现在留着更保险。

#### 备用的两条通道

| 情况 | 怎么做 |
|---|---|
| 想先看看会生成什么，不实际写文件 | `python3 同步书签.py --dry-run` |
| 手上有浏览器导出的 `bookmarks.html` | `python3 同步书签.py --from-html ~/Downloads/bookmarks.html` |
| 只连着改了很多书签，想立刻推一次 | 直接双击 `3-同步书签.command`，它每次启动都会先同步一遍 |

## 四、文件都是干什么的

日常你只会碰最上面两行，其余全是自动生成的，**不要手动改**：

| 文件 | 作用 | 你要动它吗 |
|---|---|---|
| `README.md` | 软件清单的内容源 | ✅ 常改 |
| `本地资料/使用说明.md` | 本文的内容源 | 🔘 偶尔改 |
| `同步书签.py` | 读 Chrome 书签 → 生成书签页内容，顺带做安全过滤。书签页下线期间也照常能跑 | 🔘 想调过滤规则才动 |
| `迁移书签.py` | 把被安全兜底挡下的书签，按原因搬进「不上网站」 | 🔘 被 `4-` 调用 |
| `links.md` | 书签页的中间产物，**由脚本生成**（页面已下线，内容留着） | ❌ 手改会被覆盖 |
| `lottery.html` | 彩票选号工具，独立单文件 | 🔘 想换版本才动 |
| `index.html` / `apps.html` | 线上网页，自动生成 | ❌ 手改会被覆盖 |
| `本地资料/使用说明.html`、`本地资料/help.html` | 本文的网页版，同一份内容两个名字，**只在本机** | ❌ 自动生成 |
| `build.py` | 编译脚本 | 🔘 加新页面、改配色、上下线页面才动 |
| `1-编辑内容.command` | 双击 → 打开内容源 | 🔘 双击用 |
| `2-更新网站.command` | 双击 → 编译 + 上线 | 🔘 双击用 |
| `3-同步书签.command` | 双击 → 挂起监听 Chrome 书签，本地自动更新 | 🔘 双击用（书签页下线期间用不上） |
| `4-整理不上网站.command` | 双击 → 把被自动挡下的书签收拢进「不上网站」 | 🔘 需要时双击 |
| `本地资料/` | **只在你电脑上的东西**（说明书 + 以后想放的私人资料），不提交、不发布 | 🔘 想恢复上线才动 |
| `favicon.*` / `icon-*.png` | 网站图标 | 不用动 |
| `manifest.webmanifest` | 手机加到主屏的配置，自动生成 | 不用动 |
| `robots.txt` / `sitemap.xml` | 给搜索引擎看的，自动生成 | 不用动 |
| `edgeone.json` | 托管平台的构建配置 | ❌ 不要删 |
| `docs/` | 进阶文档（备案、升级路线、内容规划） | 想看时再看 |

> **唯一要记住的规则：手写的只有 `README.md` 和 `本地资料/使用说明.md` 这两个内容源。**
> 手改 `.html` 或 `links.md` 下次更新会被覆盖，白改。
> `本地资料/` 里的东西**不会上线、也不会进 GitHub**——你可以放心在里面写。

### 彩票选号工具

### 说明书为什么只在本地

| 文件 | 什么时候用 |
|---|---|

## 五、页面上的按钮都是干什么的

### 右上角「外观」

点开是一个小面板，四个选项：

| 选项 | 作用 |
|---|---|
| **明暗** | 自动 / 浅色 / 深色。选「自动」就跟系统走 |
| **底色** | 8 种预设底色，点一下就换 |
| **自定义…** | 弹系统取色器，自己挑任意颜色 |
| **恢复默认** | 一键回到出厂配色 |

选完底色后，文字颜色会**自动适配**（浅底自动用深字，深底自动用浅字），不用担心看不清。实测标题对比度 ≥12:1、正文 ≥4.9:1，都在无障碍标准线以上。

> 设置只存在**你自己这台浏览器**里。换设备、换浏览器都是默认配色，也不影响别人，更不上传任何东西。

**想加一种底色或改预设色：** 打开 `build.py` 搜 `presets`，会看到一个数组，一行一个颜色：

```js
{name: '暖阳', bg: '#f7efd9'},
```

`name` 是鼠标悬停时显示的名字，`bg` 是底色。**加一行多一个色块，删一行少一个**（面板一行排 4 个，建议保持 4 的倍数最整齐）。

### 顶栏的其他东西

| 元素 | 作用 |
|---|---|
| **搜索框** | 全站内容都能搜。`/` 聚焦、`↑↓` 选、`Enter` 打开、`Esc` 清空 |
| **筛选项** | 「有下载链接的」只看能直接点开的；「我推荐的」只看标了 `☆` 的 |
| **折叠 / 全部展开** | 一键收起或展开所有分组 |
| **首页** | 回到导航首页 |

### 搜索的几个小细节

- 搜索时所有分组自动展开，命中的留下，没命中的自动收起。
- 分组标题右边的数字变成 **「命中数 / 总数」**，一眼看出这一类里命中几条。
- **大小写无所谓**，中文英文都能搜。
- 试试搜这几个词感受一下：`截图`、`下载`、`pdf`、`heic`。

### 从首页或网址直接跳到某个筛选

首页软件清单卡片上有两个按钮，点进去就是筛好的结果。这两个网址可以直接收藏，以后一键直达：

| 推送失败 | 网络问题。改动已存本地，网络好了重新双击 `2-更新网站.command`，不会丢 |

书签同步相关的几个（**书签页现在是下线的，下面这些问题等恢复以后才会遇到**）：

| 问题 | 原因 / 怎么办 |
|---|---|
| 收藏了，网页上没反应 | ① 先确认 `3-同步书签.command` 的窗口还开着；② Chrome 写书签文件有几秒延迟，再等十几秒；③ **默认是「攒着推送」，本地网页会更新但线上要等你在本地双击 `2-更新网站.command`**；④ 看终端里「安全兜底挡下的内容」那几行，八成是被兜底规则剔了，想放行见第三节 |

## 八、首次在 macOS 上运行的安全提示

`.command` 文件本质是可执行脚本，macOS 第一次会拦下来：

| 现象 | 处理 |
|---|---|
| 提示「无法打开，因为来自身份不明的开发者」 | **右键点文件 → 打开 → 在弹窗里再点「打开」**。只需做一次 |
| 提示「已损坏，无法打开」 | 打开「终端」，输入 `xattr -cr ` （末尾有个空格），把整个文件夹拖进去，回车 |

**为什么会有这个提示？** 因为这两个脚本没有苹果签名。它们做的事很简单：一个调 VSCode 打开文件，一个跑 `build.py` 然后 `git push`。你可以右键 →「显示包内容」，用文本编辑器打开检查，不用担心。

如果双击后终端窗口一闪就没了，说明执行出错。可以在**终端**里手动跑一次，看详细信息：

```bash
cd ~/IdeaProjects/js-ping.github.io && ./2-更新网站.command
```

| 改书签页的安全过滤 | 同一个文件里的 `AUTO_BLOCK_RULES`，按类别分组，删词即放行 |

**加一个新页面的完整步骤**（想试的时候再看）：

1. 新建一个内容源，比如 `books.md`，写法跟 `README.md` 一样。
2. 打开 `build.py`，在 `LIST_PAGES` 里加一条：

```python
dict(src="books.md", out="books.html", kicker="看过的书",
     title="书单", sub="带一句短评。", layout="list"),
```

3. 双击 `2-更新网站.command`。页面、搜索、目录、配色、导航**全都自动有**，不用再写一行代码。
4. 想让它出现在首页，再去 `OTHER_PAGES` 里加一行。

`layout` 有两个值：`"list"` 是普通清单（软件页那种），`"compact"` 是紧凑排布（书签页那种）。

**顺手再记一个更常用的开关**：想临时把一个页面撤下来（但代码和内容都留着），就在那条里加 `enabled=False`：

```python
dict(src="links.md", out="links.html", ..., layout="compact", enabled=False),
```

编译时终端会打印「已下线 links.html」，页面不再生成、首页卡片和导航也会自动消失。想恢复就把它删掉或改成 `True`——**网址书签页现在就是靠这个开关下线的**。
