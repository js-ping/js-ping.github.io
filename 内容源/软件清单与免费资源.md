## AI 工具

- 对话与写作：
    - [ChatGPT](https://chatgpt.com/)：综合能力最均衡，订阅制，需要网络环境。
    - [Claude](https://claude.ai/)：长文写作和读代码更稳，订阅制，需要网络环境。
    - [豆包](https://www.doubao.com/)：国内直连，网页版和客户端都有。
    - [Kimi](https://kimi.moonshot.cn/)：长文档一次读完，网页版免费够用。
    - [DeepSeek](https://www.deepseek.com/)：国内直连，网页版免费不限次；接口便宜，适合自己折腾。
    - [通义千问](https://tongyi.aliyun.com)：阿里大模型，网页版免费

- 本地跑模型：
    - [Ollama](https://ollama.com/)：本地跑开源大模型，数据完全不出门。命令行一行就能拉起，模型文件很占硬盘，动手前先看剩余空间。
    - [LM Studio](https://lmstudio.ai/)：本地大模型的图形界面，不写代码也能用，和 Ollama 二选一就够。
    - [Cherry Studio](https://cherry-ai.com/)：桌面客户端，能同时接好几家的接口。

- 写代码：
    - [Cursor](https://cursor.com/)：付费商业产品，订阅制带一点免费额度，但目前是换掉整个编辑器最省事的一个。
    - [Claude Code](https://claude.com/product/claude-code)：终端里的编程助手，适合已有项目里改代码。

- 出图出视频：
    - [ComfyUI](https://github.com/comfyanonymous/ComfyUI)：节点式拼工作流，可控性最高，就是上手陡，得先搞懂节点怎么连。
    - 即梦 / 可灵：国内直接用，出短视频效果够看。

- AI 应用与算力：
    - [沉浸式翻译](https://immersivetranslate.com/)：双语对照翻译网页和 PDF，浏览器、iOS、安卓都能装。
    - [NotebookLM](https://notebooklm.google.com/)：把自己的资料传上去，生成问答和摘要，答案带出处。
    - [Whisper](https://github.com/openai/whisper)：语音转文字，本地跑，中文识别不错。
    - [Hugging Face Spaces](https://huggingface.co/spaces)：免费部署 AI 应用，能跑 demo
    - [Google AI Studio](https://aistudio.google.com)：Gemini API 免费额度，调试方便
    - [Google Colab](https://colab.research.google.com)：免费在线 Python 环境，偶尔有 GPU
    - [Kaggle Notebooks](https://www.kaggle.com/code)：免费 GPU 算力笔记本，每周有额度


## 上网与隐私

- 浏览器：
    - [Chrome](https://www.google.cn/chrome/)：最完美的浏览器，可是没法登录，太膈应了。装的时候从官网下 64 位版本，不然有些插件会不管用。
    - Edge：感觉这个浏览器更同步起来更加方便一点，但是好像占用电脑CPU。
    - [Firefox](https://www.mozilla.org/firefox/)：开源浏览器，隐私保护比 Chrome 好
    - [书签同步xbrowsersync](https://www.xbrowsersync.org/)：暂时好像被禁用了。

- 社交与通讯：
    - [QQ](https://im.qq.com/download/)、[微信](https://weixin.qq.com/)：社交必备，Mac 和 PC 都要装。
    - [Signal](https://signal.org)：端到端加密通讯，非营利开源
    - [Proton Mail](https://proton.me/mail)：端到端加密邮箱，免费版 1GB

- 去广告与拦截：
    - [☆ uBlock Origin](https://github.com/gorhill/uBlock)：最强开源广告拦截器，浏览器去广告的事实标准
    - [uBlock Origin Lite](https://github.com/uBlockOrigin/uBOL-home)：MV3 版本，适配 Chrome 扩展新规
    - [AdGuard Home](https://adguard.com/adguard-home/overview.html)：自建 DNS 级去广告，全屋设备一起生效
    - [NextDNS](https://nextdns.io)：云端 DNS 过滤，免费额度每月 30 万次查询
    - [Privacy Badger](https://privacybadger.org)：EFF 出品，自动学习并拦截跟踪器
    - Adblock Plus
    - [DarkReader](https://darkreader.org/)：最好用的网页黑色模式工具，没有之一。

- 密码与账号安全：
    - [Bitwarden](https://bitwarden.com)：开源密码管理器，个人版永久免费不限条数
    - [KeePassXC](https://keepassxc.org)：本地密码库，完全离线不联网
    - [Have I Been Pwned](https://haveibeenpwned.com)：查你的邮箱和密码有没有出现在泄露库里
    - [SimpleLogin](https://simplelogin.io)：邮箱别名，注册杂七杂八的站不再暴露真邮箱

- 浏览器插件：
    - [Tampermonkey](https://www.tampermonkey.net/)：脚本安装插件。[相关脚本网站](https://www.tampermonkey.net/scripts.php?ext=dhdg)。
    - [暴力猴](https://github.com/violentmonkey/violentmonkey/releases)。
    - [Octotree](https://www.octotree.io/)：Github 网页插件。
    - [IA 图片助手](http://www.pullywood.com/ImageAssistant/)：最好用的网页图片下载工具，没有之一。
    - [哔哩哔哩过滤器](https://s.xmcp.ltd/pakkujs/?src=wext_homepage)。
    - [哔哩哔哩下载助手](https://csser.top/)。
    - [腾讯交互翻译](https://transmart.qq.com/zh-CN/download)
    - [浏览器截图插件](https://getfireshot.com/)：挺好用 ，就是官网打开有点慢。
    - [插件下载网](https://crxdl.com/)：第三方插件网站。

## 经验与备忘

- Windows 技巧：
    - 建议至少一年重置一次电脑：有些东西清不干净，只有重装才能根除。
    - 取消开机密码：win+R，netplwiz，添加一个账户，去掉对勾，删除那个添加的账户，在原先账户上弹窗输入和自己账户一样的账号密码。
    - [win11 任务栏](https://wwp.lanzoul.com/i7Bsx09zt0fe)，[win10 任务栏](https://wwp.lanzoul.com/iDK3P06gbcpg)：任务栏样式及透明设置，还是喜欢 win7 的样式。

    - 批量新建文件夹出现乱码：txt 文件右键「另存为」，编码选 ANSI。
    - 联想一键还原 + Win10 保留文件重置：电脑出问题基本都能救回来。

- 浏览器技巧：
    - 文件批量重命名：全选 →F2→ 重命名，然后就会自动批量以数字排序。

    - 重装 / 卸载之前先备份：把**密码、书签、插件**都导出来，出问题随时能恢复。
