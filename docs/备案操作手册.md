# ICP 备案操作手册

> 写给 uppjs.com（阿里云注册 · EdgeOne Pages 托管 · 个人站）
> 更新日期：2026-10-01

## 一、先把账算清楚

**结论前置**：备案本身不花钱，但**必须有一台中国大陆的云服务器**才有资格提交。真实成本 = 那台服务器。

| 项目 | 值 |
|---|---|
| 备案费用 | **0 元**（云厂商代备案全程免费，不存在"加急费"） |
| 服务器成本 | 最低档轻量应用服务器，**约 ¥68–300 / 年** |
| 提交耗时 | 约 30 分钟 |
| 拿到备案号 | **2–4 周**（管局审核 7–20 个工作日） |
| 收益 | 国内访问 **600–1400ms → 50–90ms** |
| 代价 | 页脚必须挂备案号、内容受管局监管、主体变更要报备 |

**值不值？** 要长期做这个站、在意访客打开速度 → 值。纯自己记账用 → 不值，现在这套不备案也能跑。

### ⚠️ 最大的一个认知坑

**EdgeOne Pages 是免费托管，不提供备案服务码，不能替代服务器。**

备案的法定前提是"有大陆接入服务商资源"。所谓"接入服务商"，在实操里就是**一台实打实的云服务器**。EdgeOne Pages 这种纯托管服务不算。

## 三、买哪台服务器

| 云厂商 | 产品 | 硬性要求 | 参考价 |
|---|---|---|---|
| **阿里云**（推荐） | 轻量应用服务器 | 包年包月，时长 > 3 个月 | 活动价常年在 ¥68–99/年；常规 ¥50–100/月 |
| 腾讯云 | 轻量应用服务器 Lighthouse | 同上 | 类似，新人有 ¥50–90/年 |

### 必须是这样的，否则通不过

- ✅ **包年包月**，且总时长 **大于 3 个月**
- ❌ 按量付费 —— 不行
- ❌ 免费试用实例 —— 不行（阿里云官方明确写了"免费试用 ECS 不满足可备案服务器要求"）
- ✅ 地域必须选**中国大陆**：北京 / 上海 / 杭州 / 广州 / 成都 / 南京 等
- ❌ 中国香港、新加坡、硅谷等海外节点 —— 不行（境外节点根本不需要备案）

### 三个省钱的真相

1. **这台服务器对网站速度毫无贡献**。你的站跑在 EdgeOne 的全球节点上，这台机器的唯一作用是"让备案有资格提交"。
2. **不用开机，不用部署任何东西**。买完放着就行，甚至停机也不影响备案（只要没到期）。
3. **域名在谁家注册，就在谁家备案最省事**。阿里云注册的域名 → 阿里云账号买服务器 → 备案时系统**自动生成服务码**，不用授权、不用跨账号。

> **推荐操作**：阿里云轻量应用服务器，选最便宜那档（2核2G 足够），买 1 年。

## 五、材料清单

| 材料 | 怎么弄 | 注意 |
|---|---|---|
| 身份证正反面 | 手机**原相机**拍 | 不反光、不遮角、边缘完整；JPG/PNG；200KB–4MB。**禁止截图、扫描件、黑白复印件、翻拍** |
| 域名证书 | 阿里云 → 域名控制台 → 该域名 → 「域名证书下载」 | 一行都不用改 |
| 网站名称 | 自己起 | 见第六节，这是最容易被打回的字段 |
| 网站简介 | 一句话 | 建议：「个人整理的软件与硬件使用清单」 |
| 手机号 ×2 | 主号 + 应急联系人 | 都要能接电话、收短信 |
| 邮箱 | 常用邮箱 | 收通知 |
| 人脸核验 | **阿里云 App** 扫码刷脸 | 不用幕布、不用邮寄核验单 |
| 通信地址 | 精确到**门牌号** | 只写"山东省济南市"必被打回 |

## 六、最容易被打回的五个坑

| # | 坑 | 为什么会被拒 | 怎么躲 |
|---|---|---|---|
| 1 | **网站名称含敏感词** | 「软件下载」「资源站」「平台」「资讯」「论坛」「社区」「中国 / 中华 / 门户」一律不行 | 用「个人软件使用记录」「XX 的个人技术笔记」这类中性名 |
| 2 | **网站名称与内容不符** | 你的清单里有激活工具、绿色版条目，如果网站名叫"XX 软件下载站"，等于自投罗网 | 定位成"个人使用记录 / 个人整理"，**名称里不要出现"下载"二字** |
| 3 | **域名实名主体 ≠ 备案主体** | 早期注册信息过期或挂在别人名下，核验直接失败 | 先去域名控制台看实名信息，不一致先做**域名过户**，等同步后再备案 |
| 4 | 通信地址太简略 | 只写到市 | 写到门牌号；确实没有门牌号的如实备注 |
| 5 | **短信核验超时** | 工信部短信**只有 24 小时**有效期，过期订单直接作废，全部重来 | 初审通过后紧盯手机 |

> **个人备案的内容边界**：法规上个人备案不得做电商、论坛、资讯社区。
> 你现在的形态（个人清单 + 外链）属于"个人展示"，可以通过。
> 但**备案审核期间不要临时改成带交易性质的样子**，管局可能抽查。

## 七、逐步操作（阿里云）

| 步骤 | 操作 |
|---|---|
| 1 | 登录阿里云控制台，顶部搜索框搜 `ICP备案` → 进「ICP 代备案管理系统」 |
| 2 | 点「**开始备案**」（是首次备案，不是"接入备案"、不是"新增网站"） |
| 3 | 备案类型选「网站」；性质选「**个人**」；地区选**身份证所在省份**（山东） |
| 4 | 填主体信息：姓名、身份证号、通信地址（精确门牌号）、手机号、邮箱 |
| 5 | 填网站信息：网站名称（见第六节）、域名填 `uppjs.com`（**不带 www、不带 https、不带斜杠**）、网站内容选「个人展示 / 技术类」 |
| 6 | 选云服务实例 → 系统**自动绑定备案服务码**（同账号免操作） |
| 7 | 上传身份证照片；手机装**阿里云 App**，扫页面二维码做真人核验 |
| 8 | 全部核对无误 → 收短信验证码 → 提交 |
| 9 | 等阿里云初审（**1–2 个工作日**，可能电话核实，保持手机畅通） |
| 10 | 收到工信部短信 → **24 小时内**点链接完成核验 |
| 11 | 等管局终审（山东 **7–20 个工作日**，节假日顺延） |
| 12 | 通过后收到备案号，形如 `鲁ICP备2026XXXXXX号-1` |

> 提交后信息就不能直接改了，要撤回订单重填。**第 5 步和第 8 步前，多检查一遍。**

## 九、常见问题

**Q：可以不买服务器，只备案域名吗？**
A：不行。ICP 备案的法定前提就是有大陆接入商资源。网上卖的"备案服务码"是灰色渠道，**风险自负，不建议**。

**Q：备案期间网站能开吗？**
A：能。但建议保持"个人展示"形态，不要出现交易、论坛模块。管局可能抽查。

**Q：备案要续费吗？有效期多久？**
A：备案本身**长期有效，不用续费**。但有个隐藏条件——**备案挂靠的那台服务器到期不续费，备案会失效**。这是最多人忽略的一条。每年记得续最便宜那档。

**Q：不备案会怎样？会被处罚吗？**
A：不会。你现在这套（EdgeOne 加速区域选「不含中国大陆」）**完全合法可用**，只是慢。备案不是"合法/非法"的分界线，是"快/慢"的分界线。

**Q：能不能用腾讯云备案？**
A：可以，但要腾讯云账号实名 + 腾讯云服务器。既然域名在阿里云，直接在阿里云备案少一层麻烦。

**Q：能不能备案 `www.uppjs.com`？**
A：备案填的是**主域名** `uppjs.com`，`www` 自动覆盖，不用单独备。

**Q：一个备案号能挂几个站？**
A：一个主体可以备案多个域名，但每个网站内容都要符合个人备案规则。

## 十、我的建议

**先别急着买。** 现在这套不备案也能跑。等满足下面任意一条再动手：

- 有明确的对外推广需求（从小红书 / B站 / 公众号往站里引流）
- 有访客反馈"打不开 / 太慢"
- 站点开始有实际价值（合作、变现、被引用）

真要做了，就**买阿里云轻量最便宜那档、买 1 年**，别买贵的——它对你的网站性能毫无贡献，纯粹是备案凭证。
